# Lab 2: Memory Match

Karsten Palmer — Individual

A SwiftUI memory-card layout with six pairs of animal cards. The app uses LazyVGrid and state properties. Tap a card to reveal or cover its animal.

Open `Lab2.xcodeproj` in Xcode and run the Lab2 scheme in an iOS simulator. The bundle identifier is `com.palmer.lab2`.
